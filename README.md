# 旅暦（たびごよみ）

温泉・世界遺産・御朱印の季節の判子帳。見頃の月にその場所へ行って判子を押すと、絵柄と色が変わる「季節の判子」になります。スマホ向けの Web アプリ（PWA）で、記録は端末の中だけに保存します（外には送りません）。

菓暦（かれき）の仕組みを使った兄弟アプリです。

## できること（v1）
- 地図ホーム：世界遺産・名水百選・重伝建と、季節の名所の判子。近づくと「○○まで 120m」の帯と、判子を押すボタンが出る
- 旅のしかた（徒歩 2km・自転車 10km・車 100km・電車 200km・飛行機 全国）で、出す範囲を絞る。電車・車では一覧（世界遺産・百選など）に入っている場所だけ、徒歩・自転車では近所の温泉・銭湯・神社・お寺も出す
- 場所のカードから Google マップで開く・経路を出す
- 今月のお題：今月が見頃の名所を3〜5か所
- 帳面：場所（一覧ごとの n / 全件とマス）、印（御朱印・御城印・鉄印・御船印・灯台御守印・その他を写真つきで記録。数や順位は出さない）、都道府県ごとの判子の数と47マスの表
- 日記、書き出し・読み込み（判子・印・写真）

## 動かす
```
python -m http.server     # http://localhost:8000/
node --test tests/*.test.js
node tools/build-spots.mjs   # データを作り直す（Wikidata。結果は tools/.cache にキャッシュ）
```
動作確認用に、`?date=2026-11-12` を付けると今日の日付を差し替えられます。

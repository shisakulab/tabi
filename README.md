# 旅暦（たびごよみ）

温泉・世界遺産・御朱印の季節の判子帳。見頃の月にその場所へ行って判子を押すと、絵柄と色が変わる「季節の判子」になります。スマホ向けの Web アプリ（PWA）で、記録は端末の中だけに保存します（外には送りません）。

菓暦（かれき）の仕組みを使った兄弟アプリです。

## できること（v1）
- 地図ホーム：世界遺産・名水百選・重伝建などの一覧の場所と、近所の温泉・銭湯・神社・お寺・博物館・記念館・名所・展望・パン屋・喫茶店（チェーンと支店名だけの店は除く）・定食屋（全国約11万か所）、季節の名所の判子。近づくと「○○まで 120m」の帯と、判子を押すボタンが出る
- 旅のしかたは3つ：散歩（2km）・サイクリング（10km）・旅行（一覧の場所だけ。日本の外も含め世界）
- 今日のお題：「ご飯・寺社・その他」から1つずつ。回って戻ると約30分になる道のり（散歩は時速5km＝約2.5km・約3,600歩、サイクリングは時速15km＝約7.5km）。長さは設定で15分・30分・60分から選べる（初期は30分）。根拠は厚生労働省「健康づくりのための身体活動・運動ガイド2023」
- 今月のお題（旅行のとき）：今月が見頃の名所を3〜5か所
- 場所のカードから Google マップで開く・経路を出す
- 帳面：一覧の場所を判子のマスにそろえて表示（まだは点線、押したら色）。検索つき（ひらがな・通称でも探せる）。タブは一覧・都道府県・国（176か国）。御朱印・写真・メモは日記のその日に出る
- ご当地グルメ：都道府県ごとの郷土料理の図鑑（農林水産省「うちの郷土料理」）。食べたら写真つきで記録
- 世界遺産は世界分に広げた。日本の外の地図は OpenFreeMap。日本語名のない海外の場所は英語・現地語の名前（画面は日本語のみ）
- 日記：カレンダー表示（マスには判子だけ、押すとその日の詳細）。写真が付いた判子は、カレンダーでも地図でも写真を丸く切り抜いて表示
- 写真からまとめて判子：写真をまとめて選ぶと、撮影日と撮影位置（EXIF）から近くの場所に、確かめる画面なしで判子を押す。取り込みごとに「まとめて取り消す」
- 経路（GPX）からまとめて判子：Strava・ヘルスケアなどの経路の GPX を選ぶと、通った場所にその日の判子を押す。まとめて取り消せる
- 着いたら振動・通知、押した後は次のまだの場所へ案内、見頃でない月は灰色
- データは端末の中だけに保存（外には送らない）。書き出し・読み込みあり

## 動かす
```
python -m http.server     # http://localhost:8000/
node --test tests/*.test.js
node tools/build-spots.mjs   # データを作り直す（Wikidata。結果は tools/.cache にキャッシュ）
node tools/build-foods.mjs   # ご当地グルメのデータを作り直す（農林水産省。結果は tools/.cache にキャッシュ）
```
動作確認用に、`?date=2026-11-12` を付けると今日の日付を差し替えられます。

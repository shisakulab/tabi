# 旅暦を世界に広げる計画（2026-10-13 案）

## 今のつくりで日本に縛られているところ
| 部分 | 今 | 世界にしたとき |
|---|---|---|
| 地図の画像 | 国土地理院（日本の外はほぼ白い） | 日本の外は別の地図に切り替える |
| 場所のデータ | Wikidata の一覧は P17=日本で絞っている。OSM は日本の pbf だけ | 一覧ごとに「世界」を足す。OSM は世界分を前もって作れない |
| 都道府県の帳面 | 47 都道府県の升目 | 「国」の帳面を足す（日本は都道府県のまま） |
| 名前 | 日本語の名前がないものは載せない | 世界遺産は構成資産 6,185 件のうち日本語名は 2,112 件。英語・現地語で補う |
| 季節の名所 | 日本の 55 件 | 海外の見頃（桜・紅葉・オーロラ・祭り）を手で足す |
| 旅のしかた | 飛行機＝全国（3,000km） | 飛行機＝世界 |

## 段階
### 段階1：世界遺産で世界を回れるようにする（最初の公開）
- 地図：日本の中は国土地理院のまま、日本の外は世界対応の無料タイルに切り替える（候補と規約は要調査。OSM 本家のタイルはアプリでの多用が規約で禁止なので使わない）
- データ：世界遺産の P17=日本 の絞りを外す。区画（0.5度）はそのまま使える。国は Wikidata の P17 で付ける
- 名前：日本語 → 英語 → 現地語 の順で出す
- 帳面：「国」のタブ（行った国の数と一覧）。都道府県のタブは残す
- 飛行機の範囲を世界に
- 確かめること：区画ファイルの数と大きさ、海外の場所でのカード表示

### 段階2：世界の一覧と季節の判子を増やす
- Wikidata で件数を数えてから選ぶ：国立公園、ユネスコ世界ジオパーク、ラムサール条約湿地 など
- 海外の季節の名所を手で 30〜50 件（ワシントンの桜、カナダの紅葉、北欧のオーロラ、各地の祭り）

### 段階3：海外の「近所の場所」
- 世界の OSM を前もって作るのは大きすぎる（pbf だけで 80GB 超、C ドライブも足りない）
- 代わりに、徒歩・自転車のときだけ、今いる周り 2〜10km を Overpass にその場で問い合わせ、端末に保存する
- 種類は日本の神社・お寺に当たるもの（教会・モスク・寺院）、温泉、灯台。数が多い教会をどこまで出すかは要相談

### 段階4（任意）：英語の画面
- 人に勧める・海外の人にも使ってもらうなら。旅暦の名前と判子の世界観をどう訳すかが先

## 決めてほしいこと
1. 画面の言葉は、当面日本語だけでよいか
2. 海外の「近所の場所」に教会・モスクなどを入れるか（入れると数がとても多い）
3. 最初の公開は段階1だけでよいか
